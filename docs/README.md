# Documentation Index

This folder is intentionally split by purpose to avoid duplicated content.

- `02-reference/API_REFERENCE.md`

## Documentation Policy

- Keep user-facing quickstart in root `README.md`.
- Keep low-level technical references in `docs/`.
- Avoid copying the same section into multiple files.
- Prefer linking between docs instead of duplicating entire chapters.
